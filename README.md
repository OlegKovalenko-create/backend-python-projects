# Backend Python Портфолио

## Описание

Данный репозиторий содержит мои учебные проекты на Python, направленные на изучение основ backend-разработки.

Цель — закрепление базовых навыков программирования и формирование практического портфолио.

---

## Проекты

### Task Manager (CLI приложение)
Консольное приложение для работы со списком задач.

Функции:
- добавление задач
- просмотр задач
- удаление задач

---

### API Requests Playground
Приложение для работы с внешними API.

Функции:
- получение случайных шуток
- получение фактов о котах

Используемые API:
- official-joke-api
- catfact.ninja

---

### File JSON Tools
Простой инструмент для работы с файлами JSON.

Функции:
- запись данных в файл
- чтение данных из файла

---

## Используемые технологии

- Python
- Git / GitHub
- API (requests)
- JSON
- Работа с файлами

Изучение основ backend-разработки:
